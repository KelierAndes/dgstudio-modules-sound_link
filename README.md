# 音频联动（DGStudio 模块）

DGStudio 的音频联动模块：**麦克风**与**系统正在播放的声音**（Windows WASAPI
回环）可以**同时**监听，每 0.1 秒分析一拍，每路各输出左右响度 / 左右频率
共八个**只读变量**。

本模块是**纯输入采集**：只负责「采集 → 登记变量」，**绝不直接驱动设备**。
所有设备动作（脉冲流频率、强度、波形等）都在「事件流」画布上用**写入卡**
完成——把本模块登记的频率变量接一张「范围映射」卡，再连到核心的「脉冲流
频率」写入卡即可。

## 功能

八个只读变量（`mic_` = 麦克风，`loop_` = 系统声音）：

| 变量 | 说明 |
|---|---|
| `{mic_left_loudness}` / `{mic_right_loudness}` | 麦克风左/右声道响度 0-100 |
| `{mic_left_frequency}` / `{mic_right_frequency}` | 麦克风左/右声道主频率 (Hz) |
| `{loop_left_loudness}` / `{loop_right_loudness}` | 系统声音左/右声道响度 0-100 |
| `{loop_left_frequency}` / `{loop_right_frequency}` | 系统声音左/右声道主频率 (Hz) |

变量在 DGStudio「事件流」页右侧的**变量表**里以**系统参数 · 不可改名**显示（**只读**，由本模块
每拍维护，实时值直接显示在行上）。卡片面板里**没有**「模块变量」分组——要取某个变量，
**按住变量表该行左侧的拖动柄拖到画布**，即生成该变量的读数卡（每拍输出当前值）；事件流里的
映射 / 公式 / 写入卡用 `{变量名}` 引用这些采集值。

## 安装

DGStudio「模块」页 → 在线列表找到「音频联动」→ 安装并启动（依赖自动补装）。

## 配置与使用

1. 模块页「音频联动」卡片里勾选要监听的两路（麦克风 / 系统声音）并各选设备。
2. 打开「事件流」页，把本模块的频率变量连线到设备动作（见下）；变量实时值在
   变量表与读数卡片上查看。

### 在事件流里驱动设备

模块只输出变量，动作要自己连线。以「频率驱动外部脉冲流」为例：

1. 控制页把 A/B 通道波形切到「**外部脉冲流 (PULSE_STREAM)**」。
2. 事件流里从变量表把 `{mic_left_frequency}` 那行**拖到输入页画布**生成读数卡，
   接一张 **范围映射卡**：输入区间取「音高下限 / 上限 (Hz)」（默认 20–1000），
   输出区间取设备逻辑频率 **10–1000**，并把映射方式设为**对数**（低频→低脉冲、
   高频→高脉冲）。
3. 再用一张**核心写入卡**（卡片面板「核心变量」分类，选对应通道的「脉冲流频率」
   `in_pulse_a` / `in_pulse_b`）接在范围映射卡之后。响度 `{mic_left_loudness}`
   同样拖一张读数卡，另接写入卡驱动「脉冲流电平 / 强度」。
4. 静音时频率变量归 0，映射输出随之落到下限；如需静音帧电平为 0，可在写入卡
   前用公式卡按响度做门限（`响度 < 1 → 0`）。

> 这套连线正是「频率没到峰值、脉冲流频率却仍是峰值」问题的正解：驱动只走事件流，
> 模块不再抢同一通道。

### 音频设备绑定

- **下拉选择**：「麦克风设备」「播放设备（回环）」自动扫描系统音频设备生成
  下拉选择框（麦克风 = WASAPI 录音端点；播放设备 = 可回环采集的渲染端点），
  留空用系统默认。两路互不影响，可同时开启。
- **声道绑定**：采集声道 0（物理左）→ `{dev}_left_*` 变量、声道 1（物理右）→
  `{dev}_right_*` 变量。若现场感觉左右接反，开启「左右声道交换」把两个采集声道
  对调即可（两路同时生效）。
- Windows 下同一设备会以 MME / DirectSound / WASAPI / WDM-KS 等多个宿主 API
  条目重复出现，模块一律**只绑定 WASAPI 条目**（原生混音格式、回环唯一可用），
  旧版「名称包含匹配」配置仍兼容（在 WASAPI 条目内匹配）。

### 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| 监听麦克风 | 开 | 开启麦克风那一路采集（与系统声音可同时开启） |
| 麦克风设备 | （空） | 下拉选择（自动扫描），留空用系统默认录音设备 |
| 监听系统声音 | 关 | Windows WASAPI 回环采集正在播放的声音 |
| 播放设备（回环） | （空） | 下拉选择（自动扫描），留空用系统默认播放设备 |
| 左右声道交换 | 关 | 开启后采集声道0→右变量、声道1→左变量（两路同时生效） |
| 响度增益 | 1.0 | dB 映射前乘系数，声音偏小可调大 |
| 响度 0% / 100% (dBFS) | -60 / -10 | RMS 电平线性映射到响度 0-100 |
| 响度平滑 | 0.5 | 起音指数平滑；静音立即归零（快切） |
| 音高下限 / 上限 (Hz) | 20 / 1000 | 检测频带（滑条）；供事件流范围映射卡作输入区间 |

旧版「声音来源 microphone/loopback」单选设置，以及每路的「→ 脉冲流」「映射表」
设置项，会在模块载入时自动迁移 / 清除：脉冲流推入与映射表**已移到「事件流」页面**
（用写入卡驱动），相应的旧配置项不再保留。

> 模块为**纯输入设计**（采集 → 八个只读变量）：设备动作一律由「事件流」画布的
> 写入卡驱动（宿主统一数据面），模块自身只喂信号、绝不直写设备输出。
> 响度、音高参数改动即时热生效；设备与开关按签名变化自动重开输入流。

## 常见问题

- **左右声道接反了？** 开启「左右声道交换」把两个采集声道对调即可
  （现场左右接反时使用，无需改接线）。
- **设备列表里同一个设备出现多次？** Windows 会按 MME / DirectSound /
  WASAPI / WDM-KS 等多个宿主 API 条目重复列出同一设备，模块只绑定
  WASAPI 条目，下拉里按名称选择即可。
- **装了模块却没有任何振动 / 脉冲？** 模块本身不驱动设备，需要在「事件流」里
  把频率 / 响度变量用范围映射卡 + 写入卡连到核心参数（见「在事件流里驱动设备」）。
- **没有声音反应？** 在「事件流」页的变量表里看八个变量是否随声音变化；
  声音偏小可调大「响度增益」。
